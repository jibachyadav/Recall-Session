# Recall-Session

Records a class, lets you flag confusing moments, and explains only those moments afterward.
See [PLAN.md](PLAN.md) for the full plan and build steps.

## Setup
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python app.py        # the desktop app
    python main.py       # command-line version (see usage)
